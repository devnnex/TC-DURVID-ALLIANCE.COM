# Sucursal gcobarf

Pedidos públicos: [pedidos.html](pedidos.html). Los clientes programan entregas en el calendario existente, con reserva de inventario y pago gestionado por el negocio. Consulta [la guía de pedidos en línea](../../docs/gcobarf-pedidos-en-linea.md).

Este panel usa Oracle ORDS y el motor compartido de operational/. No configura Supabase ni Apps Script.

Abre admin.html desde la tarjeta del portal e inicia sesión con tu usuario de Alliance. Usuarios abre el centro de accesos con esta sucursal seleccionada.

Consulta ../../docs/branch-operation.md para instalación, funcionamiento y alcance.
